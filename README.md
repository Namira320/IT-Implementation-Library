IT Implementation on Library 📚

A comprehensive IT system implementation project for modernizing library operations.

📖 Project Overview

This project outlines the comprehensive design and architectural planning for transforming a traditional library into a smart, technology-driven institution. By integrating high-performance networking, RFID automated systems, robust cloud storage, and security monitoring, the proposed system enhances visitor experience, operational efficiency, and overall asset security.

Key Features & Architecture:

- System Automation: Self-service book borrowing and returning through integrated RFID touch-screen kiosks, reducing queues and human error.

- Network Infrastructure (LAN): High-speed connectivity utilizing structured UTP Category 6 cabling, 24-port managed switches, and wireless modem routers.

- Security & Monitoring: Integrated CCTV surveillance (Hikvision Turbo EXIR ECO series) managed via Milestone XProtect platforms alongside RFID security gates.

- Building Management System (BMS): Automated climate control (Panasonic AC units) and resource regulation using Honeywell BMS solutions.

- Administrative Efficiency: Centralized asset tracking (Asset Panda), printing management (PaperCut), secure backup solutions (Acronis Backup), and Koha Library Management System integration.

🛠️ System Specifications Summary

1. Hardware Components
   
   - Smart Library Kiosks & Readers: ISO15693 / RFID Book Detectors & Touchscreen self-service terminals.
   
   - Surveillance & Security: Hikvision 5MP/8MP CCTV Cameras, Anti-Theft RFID Security Gates (HC-TDM02).

   - Workstations & Peripherals: HP AiO Touch PCs (Intel Core i5, 8GB RAM, 512GB SSD), Epson L3250 Multi-Function Color Printers.

   - Networking & Infrastructure: MyRepublic Wireless Modem Router, TP-Link 24-Port Gb L2 Managed Switch (TL-SG3428), Belden Cat 6 UTP Cable, Vention HDMI & Coaxial cables.

   - Environmental Control: Panasonic 2PK Non-Inverter Split AC (CS-PN18TKP).

2. Software Stack

   - Library Management: Koha Library Management System & Bibliotheca RFID Integration.

   - Security & Environment: Milestone XProtect, Honeywell BMS, HID Global Access Control.

   - Administration & Utilities: PaperCut (Print Management), Asset Panda (Inventory), Acronis Backup, Windows 10 Pro, Microsoft Office 365.

📐 Network Topology & Floor Plan

- Network Design: Structured VLAN network separating administrative PCs, book loan stations, return kiosks, CCTV feeds, and server infrastructure linked through a 24-port managed switch.

- Library Layout: Optimized zoning for bookshelf rows, reading tables, computer stations, locker storage, air conditioning units, and security checkpoint gates.
